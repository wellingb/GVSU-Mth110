    Worksheet LT 4:Linear Equations
    

    Objectives

    • Find the equation of a table of linear data
      🔗
    • Find the equation of a line parallel or perpendicular to a given line’s graph.
      🔗
    • Find the equation of a line given a point and slope.
      🔗
    • Find the equation of a line given two points..
      🔗
    🔗

    1 -3

    0 9

    3 -1

    1.

    What do you notice about the inputs for each table individually?
    🔗
    Answer.
    The \(f(x)\) table has inputs that are all increasing by adding \(1\text{;}\) starting with \(-1\text{.}\) The \(g(x)\) table has inputs that all increase by adding \(1\text{;}\) starting with \(0\text{.}\) The \(h(x)\) table has inputs that increase by adding \(3\text{;}\) starting with \(3\text{.}\)
    🔗
    🔗
    🔗

    2.

    What do you notice about the outputs for each table individually?
    🔗
    Answer.
    The \(f(x)\) table has the outputs all increasing by adding \(6\text{;}\) starting with \(-15\) The \(g(x)\) table has the outputs all subtracting \(4\text{;}\) starting with \(9\text{.}\) The \(h(x)\) table has the outputs all increasing by adding \(2\text{;}\) starting with \(-1\)
    🔗
    🔗
    🔗

    3.

    Which of the tables have linear data? Explain your reasoning.
    🔗
    Answer.
    The \(f(x)\) table has inputs that are all increasing by adding \(1\text{,}\) and the outputs are all increasing by adding \(6\text{.}\) This constant addition makes the data linear. The \(g(x)\) table has inputs that all increase by adding \(1\) and the outputs are all decreasing by subtracting \(4\text{.}\) This constant addition/subtraction makes the data linear. The \(h(x)\) table has inputs that increase by adding \(3\) and outputs that increase by adding \(2\text{.}\) Since both the inputs and outputs consistently are chaning the the same amounts, the data is linear.
    🔗
    🔗
    🔗

    4.

    What is the common difference for each table individually?
    🔗
    Answer.
    The \(f(x)\) table: since the inputs change by \(+1\) and outputs by \(+6\text{,}\) the common difference is \(\frac{6}{1}=6\text{.}\) The \(g(x)\) table: since the inputs change by \(+1\) and the outputs change by \(-4\text{,}\) the common difference is \(\frac{-4}{1}=-4\text{.}\) The \(h(x)\) table: since the inputs change by \(+3\) and the outputs change by \(+2\text{,}\) the common difference is \(\frac{2}{3}\text{.}\)
    🔗
    🔗
    🔗

    5.

    Find the y-intercept for each table of data. If it does not exist in the table, explain how you found it.
    🔗
    Answer.
    The f(x) table has the point \((0, -9)\text{.}\) The \(x\) is always \(0\) for a y-intercept. The g(x) table has the point \((0, 9)\text{.}\) The \(x\) is always \(0\) for a y-intercept. The h(x) table does not have the y-intercept in it. If you go back \(3\text{,}\) by subtracting \(3\) (instead of adding \(3\) to go forward), in the input \((x)\) column, you get \(x=0\text{.}\) Going backward in the output \((y)\) column, you need to subtract \(2\text{,}\) and find the \(y=-3\text{.}\) This means the y-intercept is \((0,-3)\text{.}\)
    🔗
    🔗
    🔗

    6.

    If the data is linear, find the equation.
    🔗
    Answer.
    All of the equations are linear. To find the equation, we use the common ratio as our \(m\) and the \(y\) of the y-intercept as our \(b\text{.}\) \(f(x)=6x-9\) \(g(x)=-4x+9\) \(h(x)=\fra{2}{3}x-3\)
    🔗
    🔗
    🔗

    7.

    Find the equation of the graphed line. Show all of your work.
    🔗
    Answer.
    First find the y-intercept.This tells us the \(b\) of the equation. Next find the slope by using rise over run. Start with a point on the left. Go up (positive rise) or down(negative rise) to get across from the next point you want to use. Then go left (negative run) or right (positive run) until you are on the line. The fraction rise/run is the \(m\) of the equation.
    🔗
    Using the y-intercept and the point (1,1): The y-intercept is (0,2), so we know that \(b=2\text{.}\) To find the slope, use rise over run. Start with a point on the left which is the y-intercept in this case. Go down(negative rise) to get across from the next point you want to use. We go down 1, so our rise is -1. Then go right (positive run) until you are on the line. We go to the right 1, so our run is +1. Rise/run = \(\frac{-1}{1}=-1\)
    🔗
    🔗
    🔗

    8.

    Find the equation of any line that is parallel to the graphed line.
    🔗
    Answer.
    We found the slope of the line to be 6. Parallel lines have the same slope but different y-intercepts. Answers will vary, but all equation need the same slope. One example: \(g(x)=6x-9\text{.}\)
    🔗
    🔗
    🔗

    9.

    Find the equation of the line in slope-intercept form: \(y=mx+b\text{.}\) The line has a slope of \(m=0\) and contains the point \((4,6)\text{.}\)
    🔗
    Answer.
    We are given \(m=0\text{,}\) \(x=4\text{,}\) \(y=6\text{.}\)
    \begin{align*} 6=0(4)+b\amp \\ 6=b \amp \end{align*}
    The equation is: \(y=6\text{.}\)
    🔗
    🔗
    🔗

    10.

    The line contains the points (-3,6) and (3,-12)
    🔗
    Answer.
    First find the slope between the two lines.
    \begin{align*} m=\frac{-12-6}{3-(-3)} \amp \\ \amp\frac{-18}{6} \\ \amp -3 \end{align*}
    Next, choose either point to represent \(x\) and \(y\) to plug into the equation. We will use (-3,6)
    \begin{align*} 6=-3(-3)+b \amp \\ \amp 9+b \\ -3 \amp b \end{align*}
    \(y=-3x-3\)
    🔗
    🔗
    🔗

    11.

    The line contains the points (5, -2) and (5,1).
    🔗
    Answer.
    First find the slope between the two lines.
    \begin{align*} m=\frac{1-(-2)}{5-5} \amp \\ \amp\frac{3}{0} \\ \amp undefined \end{align*}
    Since the slope is undefined, we know it is a vertical line. \(x=5\text{.}\) This is evident in the given points, since both points have the same x-value of 5. \(y=-3x-3\)
    🔗
    🔗
    🔗

    12.

    Answer the questions about the parameters of the equation; always comparing to the parent function equation \(y=x\)
    🔗

    (a)

    Given \(f(x)=-2x+4\text{,}\) without graphing, explain how this line differs from the parent function.
    🔗
    Answer.
    Because of the -2, we know this line is decreasing instead of increasing, and it is steeper than the parent function. The +4 tells us that all points on this graph move up 4 units.
    🔗
    🔗
    🔗

    (b)

    Given \(f(x)=0.5x+2\) and \(g(x)=2x\text{,}\) without graphing:
    🔗
    • Which line is flatter? Explain how your know from the equations
      🔗
      🔗
    • Which line has the smallest y-intercept? What is it?
      🔗
      🔗
    Answer.
    The \(f(x)\) graph would have the flatter line because its slope of 0.5 is smaller than the slope of \(g(x)\text{,}\) which is 2.
    🔗
    The \(g(x)\) graph has the smaller y-intercept which is (0, 0). The y=-intercept of \(f(x)\) is (0,2)
    🔗
    🔗
    🔗

    (c)

    Write the equation of the line \(h(x)\) that has a very steep, negative slope and a y-intercept that is below the x-axis.
    🔗
    Explain your thinking. Then draw your \(h(x)\) graph by hand - without using a graphing technology.
    🔗
    Answer.
    Answer will vary. One example is \(h(x)=-5x-3\text{.}\) The slope is -5 because the farther away from 0 in the left direction, the steeper the line. The y-intercept (the \(b\)) needs to be any negative number.
    🔗
    Put your equation into a graphing technology to check for accuracy.
